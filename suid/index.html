02Method

The direction stays human.

I use AI as the production system. The product judgment, prompts, testing, and decisions stay with me.

  1. 01

    Specify

    Turn the idea into a concrete experience, a brief, and a testable path through it.

  2. 02

    Direct

    Run AI agents through the build with clear plans, constraints, and feedback.

  3. 03

    Test

    Use the product like a real person would. Catch the rough edges before launch does.

  4. 04

    Ship

    Deploy, connect the domain, observe behavior, and improve the next version quickly.
